# 搜索中的谐音、缩写与证据

用于理解已经存在的帖子、扩展检索词。不要把作者使用变体的原因一概判断为规避审核，也不要将本参考用于编写规避审核的发布内容。

## 先保留用户真正的约束

把问题拆成需要验证的能力，避免只搜产品名字。例如本地程序化交易与 tick 同步应分别检索：策略运行位置、外部 Python/API、本地文件或数据库接入、历史 tick 补数、实时全市场行情、每日下载额度。能交易不等于能获取数据，云端撮合/柜台不等于策略必须在云端运行。

## 查询扩展

1. 先用规范名称与核心需求做短查询；结果稀少才扩展，避免堆叠很多词。
2. 从实际标题、正文、图片文字、评论收集变体，保存原文和出处，再用变体补搜。平台拼写和领域缩写不必都是“黑话”。
3. 每个核心概念选少量有依据的变体；逐个查询、按笔记 ID 去重。比较综合与最新结果，最新排序不能代替核对发布日期。
4. 对含糊表达保留多个解释，结合相邻词、单位、作者上下文判断；必要时标注“疑似”，不能凭简称确定券商。

## 种子候选（不是已核验词典）

下列仅作待验证的检索假设；未获得原文和上下文佐证时，不得写成该平台的确定释义。

| 可能遇到的形式 | 候选含义 | 判定边界 |
|---|---|---|
| mini qmt / miniQMT / 极简 QMT / 小 QMT | miniQMT | 需确认确实指外部接口模式，不把普通 QMT 一起归入 |
| 大 QMT / 标准 QMT / 普通 QMT | QMT 内置策略模式 | 运行位置与权限另查产品文档、券商版本 |
| PTrade / p trade / ptrade | PTrade | 与其他同音名称分开验证 |
| tick / 分笔 / 快照 / 逐笔 | 不同细粒度数据 | 快照不等于逐笔成交或逐笔委托；五档不等于 Level-2 |
| 米 / w / W / 万 / 个 | 金额、数量或口语代称 | “10 个”单位不明时不换算为 10 万；也可能是其他语境 |
| 券商首字母、某某家、动物/颜色代称 | 可能指某机构 | 多义；没有同帖明确全称或其他独立证据就保留匿名 |
| 开 hu / 开户变体、佣 jin / 佣金变体 | 开户或佣金的候选谐音/混写 | 仅在实际观察到后扩展，不批量生成任意拼音 |
| 私 / 滴滴 / 踢我 / 🛰 / V | 联系或私信线索 | 不能因此认定报价、身份或可开通；不自动发消息 |

## 证据卡与更新

对会改变结论的释义记录：`原始词形、原句短摘、候选标准词、领域、置信度、笔记ID/公开链接、发布日期、查阅日期、确认依据`。不要保存 Cookie、登录二维码、完整评论语料或个人联系方式。xsec_token 只放临时请求上下文，不作为公开词典内容。

置信度：
- 已确认：同帖明确解释，或上下文排除歧义并有独立来源佐证。
- 疑似：上下文吻合，但仍有合理的其他解释。
- 未知：证据不足；不据此作开户、费用、权限判断。

可复用词条加入本参考时带领域、出处和日期；只出现一次且无法解释的词不升级成全局映射。研究结论明确区分用户实测、作者自述、营销招揽和官方说明。同一句营销文案被多个账号转载不算独立佐证。

## 读取与引用

搜索结果只证明检索命中；关键主张必须打开正文，必要时读图片及评论。若工具只返回图片 URL 而没有图片文字，明确尚未读取，不假装 OCR 已完成。

金融、价格、开户等时效性结论用官方来源交叉核对，保留券商、产品版本、日期、资金口径和附加条件；不同券商、营业部或时期的信息不能拼成一个承诺。

## 无结果与失败

区分真实空结果、工具超时、登录失效、验证码/验证页。一次超时可去掉筛选或简化关键词后有限重试；连续失败停止批量请求，记录错误并告知未完成，不得把错误说成“小红书没有相关内容”。遇验证页交给用户完成，保留会话，不清除 Cookie 或绕过验证。

## 已观察样例（2026-11-01）

仅保留帮助消歧的短摘；以下不是券商政策或开户承诺。

- `10个`：在 [QMT 受限讨论](https://www.xiaohongshu.com/explore/6ac8943000000000020289db)（笔记 2026-10-09）评论出现“10个就能开通qmt”。可疑似理解为资金门槛口语，但句子没有明确币种、单位、时点/日均口径和具体券商，因此不能直接输出“10万元即可开通”。置信度：疑似，需核实。
- `mini / 大qmt`：同帖回复“mini早不能用了，现在说的是大qmt了”，可确认这条讨论将两种模式区分；不能据此推出所有券商统一停用。置信度：本帖用法已确认。
- `桥 / 文件桥`：在 [MiniQMT换大QMT](https://www.xiaohongshu.com/explore/6ad38ff1000000000a026c50)（笔记 2026-10-17）正文将“本机文件桥”解释为交换请求与应答，评论“桥还能用”指该桥接机制。这里是技术简称，不是自动认定为规避审核的谐音。置信度：本帖用法已确认。
- `兔子酱`：出现在上述 QMT 受限笔记的情绪表达中，正文没有明确指称。不还原为具体机构、券商或政策制定方。置信度：未知；不作为平台或券商查询别名。

同一讨论中同时有“无限制”“外部文件读取都关了”等相反说法，必须保留日期、产品版本和券商范围。标题或评论不能替代截图内容；截图中的无署名通知也不能推断为全行业正式公告。
